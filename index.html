📖 名词表（一个东西一个名字）
  • 书库页 — 打开软件看到的第一页，列着所有小说。左上角招牌写「📚 书库」，旁边的「📥 导入 / 📤 导出」都属于书库页。（以前叫过"首页 / 书籍页 / 小说列表"，现在统一叫书库页。）
  • 小说库 — 磁盘上存小说的文件夹，文件夹名字就叫 小说库，书库页工具栏的「📁 打开库文件夹」直接打开。三个"书"的分工：书库＝所有小说的总和，书库页＝列着所有小说的那一页，小说库＝文件夹。
  • 词条主页 — 一本书最上面的画布（根词条所在层），每本书各有一个。书里工具栏那颗 🏠 主页（悬停提示写"回到词条主页（根词条画布）"）就是回到这里。
  • 画布 — 放置词条的区域，可缩放 / 框选 / 拖动。进到某个词条里，看到的就是它的画布；「← 返回」按进出的路径逐级退，「▲ 上级」直接回上一层。
  • 词条 — 画布上的方块，也叫卡片。单击看详情页，双击进入它的下一层；删除一个词条，它下面的子词条一起进回收站，根词条不能删。
  • 节点 — 不是术语，只是新建时的默认标题：新建词条时标题留空，卡片就叫「新节点」，随手改成你要的名字即可。界面和帮助里其他地方一律说「词条」。
  • 详情页 — 显示选中词条标题 / 摘要 / 正文的区域，宽度可拖。词条的背景色 / 背景图、文字颜色都在里面改。

设置分两类，都在 ⚙️ 设置 里：🖥️ 全局设置＝所有书共用（自动保存、主题、词条默认显示方式…）；这本书＝只动当前打开的那本书（初始化这本书、重置本书样式…）。分界线和两处"会连带动全局项"的例外，见下面的「⚙️ 设置」与「🖥️ 全局设置与初始化」。

⌨️ 快捷键
  • Ctrl+A — 全选当前页的所有词条（在输入框或详情正文里则是全选文字）
  • Ctrl+F — 详情页内查找 / 替换
  • Ctrl+S — 保存当前项目
  • Ctrl+N — 新建词条
  • Ctrl+C / Ctrl+V — 复制 / 粘贴词条（支持多选，多选复制按编号顺序放进剪贴板，粘贴也按这个顺序依次落位；只在画布区域内生效，在工具栏/详情页里是普通的复制文字）
  • Ctrl+X — 剪切词条，相当于「移动」：到目标画布 Ctrl+V 即可；不想移动了按 Ctrl+Z 撤回
  • Ctrl+Z — 撤销（删除、移动、换色、连接等）
  • Enter — 确认创建 / 跳转
  • Ctrl+Enter — 摘要/正文中换行
  • Delete — 删除选中的词条
  • Esc — 关闭弹窗 / 退出模式 / 退出词条或小说页面
  • 单击卡片 — 查看详情；双击卡片 — 进入子画布
  • 长按空白处拖动（左键或右键）— 框选多个词条（右键菜单可删除/换色/排列）
🧰 工具栏（窗口顶部工作区）
  • 📂 退出 — 退出当前项目，回到书库页（会先保存）
  • ← 返回 — 沿进入路径逐级退回；▲ 上级 — 直接回到父词条 / 源词条层级；🏠 主页 — 回到词条主页（根词条画布）
  • ✖ 取消模式 — 一次性退出所有模式（多选 / 连接 / 防误操作等）
  • 🔒 防误操作 — 禁止拖拽和框选词条（防止手滑挪动布局），不影响跳转；本次运行内对这本书一直有效，重启软件后重置
  • 🔗 连接 — 连接模式：点两个词条创建连接线；再次点击它们或右键连接线可删除
  • ♻️ 回收站 — 恢复或永久删除已移除的词条
  • ➕ 新建 / 💾 保存 — 新建词条 / 手动保存
  • 🔢 / 📄 搜索框 — 左边图标切换「编号·标题跳转」与「正文搜索」，回车跳转；右边 ✕ 一键清空（帮助弹窗里的搜索框同样有 ✕，而且它悬浮在正文上方、正文从它下面穿过 —— 展开小节往下翻时随时能改词，它也不占正文的高度）
  • 🔄 重启软件 — 在帮助弹窗右上角、标题栏那个位置：点它会先保存，然后重启；重启后会自动回到你重启前待的地方（那本书 + 那个画布层级 + 滚动位置 + 选中的词条）。手动关掉软件再打开则不会自动进入，始终从书库页开始
🖱️ 右键菜单
  • 编辑词条 — 改标题、摘要、正文；引用词条还能填「别名」（最多 20 字）
  • 换颜色 / 批量换色 — 改卡片背景色、文字颜色；也能换成图片背景（切到「背景图片」页，可选 铺满 / 完整 / 拉伸）
  • 复制 / 剪切 — 复制可以反复粘贴；剪切是「移动」，粘一次就结束（Esc 取消、颜色恢复）
  • 新建子词条 — 直接进入该词条并在里面新建（之后可用「← 返回」退回来）
  • 锁定内部 / 锁定本页 / 解除锁定 — 让该页不参与自动排列（缩放窗口、初始化），手动排列不受影响，卡片上会显示 📌
  • 删除 — 直接删除（不弹确认）；可在回收站找回，也能 Ctrl+Z 撤回
  • 粘贴 / 撤销 — 画布空白处右键可用（撤销等同 Ctrl+Z）
  • 按编号排列 / 按位置排列 — 前者按编号重排；后者只按当前坐标摆整齐，不改变相互顺序
  • 批量编辑 / 批量重命名 / 排列选中 — 多选后右键：统一改内容、按序号批量命名（输入 第{n}章，或直接输入 第五章 自动从第五章递增；每次都是空白开始，不会记住上次用过的模板 / 起始序号）、把选中的整齐排到下方
  • 画布背景 / 详情页背景 / 导入文件 / 导出 Markdown — 都在画布空白处的右键菜单里
🎨 画布与详情页
  • 单击卡片 — 查看详情；双击卡片 — 进入子画布；长按空白拖动（左键或右键）— 框选多个词条
  • 🧩 子词条数量 — 卡片下方显示它有多少个子词条（移动时不显示）
  • ⧉ 复制编号 — 编辑词条时，可直接复制其编号
  • 🔢 字数 — 详情页底部与编辑词条弹窗会显示字数统计。换行与空格不计入
  • 🔗 引用信息 / 别名 — 编辑引用词条时会显示它引用自哪个词条、被引用了多少次；可填「别名」（最多 20 字）优先显示，不填则显示源词条标题（最多 10 字，源词条改名后会跟着变）
  • ✂️ 剪切 / 粘贴 — Ctrl+X 后词条半透明（内容进剪贴板）→ 到目标画布 Ctrl+V 完成「移动」；剪切是单次的（粘一次即结束）；按 Esc 或 Ctrl+Z 取消（颜色恢复）。复制 Ctrl+C 可反复粘贴
  • 🖱️ 拖放移动文本（详情页的正文 / 标题 / 摘要里都能用）— 选中一段文字 → 按住左键拖到目标位置松手，这段文字就移动过去了；按住 Ctrl（或 Alt）拖 = 复制。拖动过程中会有一根竖线指示落点（贴在插入位置，空行也能自动贴到该行最前面）；松手后这段文字保持选中、竖线在末尾闪一下再消失，按 Ctrl+Z 可撤销（提示「移动文字 / 复制文字」）。
    · 可以跨块：正文里的字能直接拖到标题 / 摘要（反过来也行），两边都会保存；
    · 拖到详情页的上 / 下边缘会自动滚动（越靠边滚得越快），所以能拖到当前看不见的位置；
    · 拖到"选中文字自己内部"不算有效落点（此时不显示竖线）；
    · 从别的软件（记事本 / 浏览器 / 别的窗口）把文字或链接拖进正文，会按纯文本插到落点（链接只会变成一段文字，不会跳转）；
    · 拖 TXT / MD 文件进窗口仍然是「导入成词条树」，不受影响
  • ↩ 撤销 — Ctrl+Z 或右键菜单；换色 / 清除背景（词条·画布·详情页）/ 重置样式 / 初始化都能撤回；退出书籍会清空撤销记录（避免在别的书里误撤回上一本的修改）
  • ⇔ 详情页宽度 — 详情页底部左侧的 ⇔ 可拖动调整宽度（向左拖变宽），旁边 ↺ 一键复位；宽度会被记住（也能在 ⚙️ 设置 →「🖥️ 全局设置」里选 300 / 400 / 480 / 560 的预设）
  • 跟随画布背景 — 详情页背景面板最上面的开关：勾上后详情页不再单独设背景，而是用画布那张背景图，并且这张图会一直铺到详情页那边（画布 + 详情页连成一张，"延伸过去一部分"的观感；此时下面的颜色 / 图片 / 显示方式会灰掉，统一去画布背景里改）。不勾 = 详情页自己一套背景（和以前一样）
  • 卡片底色透明 — 词条右键「换颜色」→「背景图」页里的小开关（仅对词条背景生效）：默认卡片底色是白的，背景图如果有透明区域（PNG）或没铺满（"完整显示"），就会露出一圈白边；勾上后底色透明，直接透出画布背景。选了图片背景会自动打开，换成纯色背景会自动关掉；没选图也能手动开（卡片会变成"只见文字和边框的透明块"）
  • 🎨 自定义颜色 / 取色器 — 颜色块下面的取色器是系统取色器：打开它以后，在窗口顶部那一排点 RGB / HEX / HSL 就能切换输入方式（想把颜色写成 #4a90d9 这种就切到 HEX；右边那串 #xxxxxx 就是当前值 —— 它本身是个输入框：可以直接选中 / 复制 / 粘贴 / 剪切，改完按回车生效（系统取色器那个小窗口里的输入框不吃剪贴板，所以想粘贴颜色值请用这一串））。另外 ⚙️「🖥️ 全局设置 → 词条默认文字颜色」里还有一排常用色块（最左边是内置默认色、最右边是自定义选色），它旁边的颜色值输入框同样能复制 / 粘贴
  • 背景图缓存 — 所有背景图都存在「小说库 / 背景图片缓存」，整个书库共用；在「背景图」页能看到占用（缓存 N 张 · X MB）并一键「🧹 清理缓存」，只会删掉任何书都没用到的图片
✂️ 背景图裁剪（词条 / 画布 / 详情页）
  • 在哪打开 — 词条右键「换颜色」→「背景图」页点 ✂️ 裁剪；画布空白处右键「画布背景」→「背景图」页；详情页「详情页背景」→「背景图」页
  • 裁剪框 — 框里拖动 = 移框；整条边、四个角都能拉大拉小（不用非要点边中间那个小方块）
  • 图片 — 框外拖动 = 挪图片；滚轮 或 ➕➖ = 缩放图片
  • 快捷键 — Shift 等比缩放、Ctrl 从中心缩放、Alt+拖动 = 重新拉一个框
  • 比例 — 自由 / 1:1 / 自适应。自适应会根据选中“词条/画布/详情页”的当前比例自动调整选框。此外，开启详情页背景面板中「跟随画布背景」时，自适应中会出现"画布 + 详情页"的全屏比例
  • 打开时 — 和「🔳 原图」一样：图片完整显示 + 框刚好框住整张图。所以什么都不改直接点「裁剪并应用」＝原图本身（像素一点不差、不会白裁掉一块）。图片比例和裁剪区对不上时，上下或左右会留一点舞台底色，这是正常的
  • 🖼️ 居中最大 / 🔳 原图 — 居中最大：把图片放大到刚好铺满裁剪区（结果＝裁掉一部分）；选着比例时（比如「自适应·词条」「1:1」）框还会按这个比例在图片里居中放到最大；比例是「自由」时框＝图片 ∩ 裁剪区（就裁你现在看到的这一块）。两种情况都不锁比例，接着拉边角还是自由的。🔳 原图：图片完整显示 + 框刚好框住整张图＝刚打开时的状态；想按原图的形状框一小块，点完它按住 Shift 拉角就行
  • 🔒 锁定裁剪框（弹窗右侧的开关，默认开） — 锁定：① 裁剪框只能在图片里活动，拖不出图片（结果不会有透明块）；② 图片也不会被拖出裁剪区，缩小到最小＝整张图刚好显示全（图片比例和裁剪区对不上时两边留一点空白，正常；但不会像以前那样一直缩下去）。拉边角撞到图片边界时框会整体等比收回来，比例锁不会被挤变形。解除锁定：框可以框到图片外面，框外那部分在结果里是透明的（想做"详情页标题那条不要图、其余有图"就用这个），图片也能随便拖、随便缩 —— 但同样不是无限缩：缩到"结果刚好 7000px（结果最长边上限）"就停住并提示你（以前没这个下限：缩到最小再应用一次，图片内容就被压小一圈，可以无限缩下去）。也能在 ⚙️ 设置 →「🖥️ 全局设置」里改（那一块自带「恢复默认」）；🪟 初始化这本书勾着「同时把全局设置恢复默认」时会把它恢复成默认的「锁定」
  • 图片不会被拖没 — 解除锁定时也至少留一条边在裁剪区里（锁定时根本拖不出去）
  • 导出格式 — 框里有透明像素 → PNG（透明原样保住）；整块都是不透明的图 → JPEG（体积小）。所以把上一轮裁出来的透明区再裁一次，透明还是透明，不会被填成白底。结果最长边上限 7000px：超了只把多出来的透明边裁掉，图片内容（原图像素）不会被缩小；只有原图自己超过 7000px 时才整体缩一点（弹窗里会写着）
  • 安全 — 裁剪只新增一张图到背景图片缓存，原图和以前用过的图都不会被改写（没有任何书在用的旧图可随「🧹 清理未引用的背景图片」回收；「🪟 初始化这本书」之后会自动问一次要不要顺手清理，点「保留」就什么都不动）
⚙️ 设置（标题栏右上角齿轮）
  • 🖥️ 全局设置（⚙️ 面板最上面、默认收起的一块，对所有书生效） — 这一块里的项都是"改一次、每本书都跟着变"；具体哪几项、每一项的「恢复默认」和底部的「↩ 恢复全部默认设置」怎么用，下面「🖥️ 全局设置与初始化」一节列了一张对照表，这里不重复。只单独提醒：自动保存间隔有 0.3 / 1.5 / 3 / 8 秒四档；想改成手动保存，把「自动保存」右边的小开关关掉（关掉后按 Ctrl+S 或点工具栏 💾 保存；退出项目 / 关闭软件时，如有未保存的改动，会弹窗询问是否保存）
  • 💾 立即备份当前书 — 复制一份到「小说库 / 备份」，文件名带时间戳
  • 词条默认显示方式（在「🖥️ 全局设置」里） — 词条背景图默认显示方式、词条粘贴位置、词条默认文字颜色。改完会记住：新建词条、以及没单独设过文字颜色的词条都会用它；被「重置 / 初始化」带到时怎么处理，见下节的"例外"
  • 🧹 清理未引用的背景图片 — 扫整个书库（所有书 + 书籍回收站）：只有"任何书都没用到"的图片才会被删；同时会列出失效引用（书里指向的图片已经不在了，那些位置显示不出背景，需要重新选图）
  • 📂 查看缓存文件夹 — 背景图片都存在「小说库 / 背景图片缓存」里，整个书库共用这一个目录（随书一起走，换电脑直接拷「小说库」就行）
  • ✂️ 裁剪 / 🧹 清理缓存 — 词条颜色浮窗和详情页面板的「背景图」页里也各有一份：裁剪当前这张背景图、看缓存占用并一键清理（打开文件夹统一放在这里）
  • 🧽 临时文件自动清理 — 打开 / 关闭软件时自动删掉程序目录里调试遗留的临时脚本与日志（_test*、_chk*、_tmp*、_b数字.txt、_*.log 等），绝不会碰「小说库」里的任何文件
  • 🎨 重置本书词条样式 — 词条颜色按系统配色重新分配，文字颜色与背景图恢复默认；⚠️ 会连带把全局的「词条默认文字颜色」一起恢复（原因见下节"例外②"）
  • 📄 重置本书详情页样式 — 详情页的背景、文字颜色恢复默认；⚠️ 详情页宽度是全局的，这一步也会把它恢复成 400px（原因见下节"例外①"）
  • 🔗 清空所有连接线 — 删除这本书里的全部连接线（词条本身不受影响）
  • 🪟 初始化这本书 — 画布、词条、详情页恢复默认样式，清空回收站，取消所有连接线，清除所有模式，解除所有单页锁定，重新编号并排列词条（不会删除正常词条）。确认框里有一个默认勾着的「同时把全局设置恢复默认」，勾与不勾各是什么结果，见下节
  • ↩ 恢复上次重置 — 回退到某次重置之前的状态，最多保留最近 10 次。记录只属于当前这本书：换书 / 打开别的书时会自动清空（不会再出现"把这本书变成另一本书重置前的样子"）
🖥️ 全局设置与初始化（哪些设置是所有书通用的）

⚙️ 设置面板最上面那块「🖥️ 全局设置 · 对所有书生效」是收起来的：点一下标题展开。里面每一项都是改一次、每本书都跟着变，和"这本书的内容"分开。标题下面那行小字会一直显示当前值，收起也能一眼看到现在是哪样。

  • 全局（所有书共用）：自动保存（开关 + 间隔）、主题（深 / 浅色）、词条背景图默认显示方式、词条粘贴位置、词条默认文字颜色、详情页宽度、🔒 锁定裁剪框 —— 共 7 项，和设置面板里那一块一一对应
  • 每本书自己的：词条内容 / 颜色 / 文字颜色 / 背景图 / 别名、画布背景、详情页背景与文字颜色、连接线、回收站、单页与内部布局锁定（📌）、书的 🔒 交互锁

恢复默认：每一项旁边都有一个小「恢复默认」；整块底部还有「↩ 恢复全部默认设置」（会再确认一次）。这些只动设置本身，不会碰任何一本书的内容。

🪟 初始化这本书：确认框里有一个默认勾着的「同时把全局设置恢复默认」——勾着就是老习惯（这本书 + 全局设置一起回默认）；取消勾选则只重置这本书，上面那些全局设置一根汗毛都不动。（「↩ 恢复上次重置」只管书里的数据，全局设置不在还原范围内。）

设置面板下半部分的「重置 / 初始化」基本上只动这本书：上面那块「🖥️ 全局设置」里的项不在这里重置，要改就去上面改。
⚠️ 例外只有两处（设置面板里也在各按钮下面的小字里写明了）：
① 「📄 重置本书详情页样式」——详情页宽度是全局的，它也会把宽度恢复成 400px（所有书共用）；
② 「🎨 重置本书词条样式」——会把词条默认文字颜色（全局）一起恢复默认（别的书也跟着变）。

📌 这些设置记在这台电脑的程序配置里（不写进书文件）：所以换电脑时拷走「小说库」不会带走它们，在新机器上重设一次即可（想从头来就点「↩ 恢复全部默认设置」）。
